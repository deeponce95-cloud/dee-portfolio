# Dee — Virtual Assistant Portfolio

This is the complete GitHub Pages-ready website for Dee.

## Files

- `index.html` — website homepage
- `assets/profile.jpg` — profile photo
- `.nojekyll` — tells GitHub Pages to serve this as a static site
- `README.md` — setup information

## Publish with GitHub Pages

1. Create a **public** GitHub repository.
2. Extract this ZIP on your computer.
3. Upload the **contents inside this folder** to the root of your repository.
4. Make sure `index.html` is directly in the repository root.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
7. Click **Save** and wait for GitHub Pages to deploy.

Your repository should look like:

    index.html
    README.md
    .nojekyll
    assets/
        profile.jpg

Do not upload the ZIP file itself as the website files, and do not put
`index.html` inside another folder in the repository.
